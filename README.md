🎓 Student Marks Prediction System

A simple Machine Learning project built using Python and Linear Regression to predict students' final marks based on study habits and academic performance.


🚀 Features
Predicts final exam marks using:
Study Hours
Mid Semester Marks
Attendance Percentage
Assignments Completed
Sleep Hours
Uses Linear Regression from Scikit-learn
Includes:
Model training:
-Accuracy evaluation (R² Score)
-MAE (Mean Absolute Error)
-Data visualization using Matplotlib & Seaborn
-Applies realistic rule-based adjustments for better predictions



🛠 Technologies Used
Python
Pandas
Matplotlib
Seaborn
Scikit-learn



📊 Machine Learning Concepts Used
-Linear Regression
-Train-Test Split
-R² Score
-Mean Absolute Error (MAE)



▶️ How to Run
Install required libraries:
pip install pandas matplotlib seaborn scikit-learn
Run the Python file:
python app.py
Enter student details when prompted.



📁 Dataset
The project uses a CSV dataset named:
student_data.csv
